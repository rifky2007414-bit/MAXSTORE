MAXSTORE FULL PACKAGE
1. Upload this folder to GitHub/Vercel as a static site.
2. Deploy Code.gs as the Google Apps Script Web App and use the same spreadsheet.
3. Required sheets: Users, Products, Sellers, Orders, Cart, Wishlist, Reviews, Notifications, Withdrawals.
4. The package includes buyer storefront/cart/checkout/orders, seller product/order/earnings/withdrawal pages, login/register, and core Apps Script routes.
5. Online payment gateway, admin UI, chat, coupons, flash sales, and production-grade authentication/payment verification are not fully implemented in this starter package and require provider/backend work.
